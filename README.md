# Bloem Sefa – store demo

A demo of the Bloem Sefa WooCommerce plant shop that runs entirely in the browser with WordPress Playground.

- Store: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/bloem-sefa-demo/main/blueprint.json
- Store admin (plants, stock, orders, pop-ups, sign-ups): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/bloem-sefa-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test orders are not kept.
